# Rocket-Propulsion-Homework-Project-2025-Psyche-Mission-Trajectory-and-Propulsion-Analysis
Rocket propulsion project on NASA’s Psyche mission: ΔV and propellant mass estimates for the real launch profile (Falcon Heavy), a direct trajectory and a Hohmann transfer to asteroid (16) Psyche, plus gravity assists, the Oberth effect, orbit insertion and Hall-effect vs chemical thrusters.
